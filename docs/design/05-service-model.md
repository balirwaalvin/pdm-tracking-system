# 5. Service model and value proposition

*Phase 2 · Model and value proposition (8 marks)* · **Owner:** Kutosi Pius · **Reviewed by:** Ogenrwot Churchill, Kato Sharif Achen (sign when checked)

## 5.1 Model: G2C, with G2B and G2G parts

| Relationship | Who | What the system provides |
| --- | --- | --- |
| **G2C** (government to citizen), the main model | Households | Eligibility check, status, receipts, SMS and USSD, complaints, appeals |
| **G2B** (government to business) | PDM SACCOs and enterprise groups | Eligibility checklist, fund releases, appraisal, payout and repayment records |
| **G2G** (government to government) | Parish, sub-county, district, PDM Secretariat, auditor | One shared record, dashboards, reports, audit trail |

Public value, not revenue: the service is **free at the point of use**. There are no fees, no payments through the system, and no e-commerce.

## 5.2 Public-value canvas

| Block | Content |
| --- | --- |
| **Users** | Households in the subsistence economy; ten official roles from village to ministry |
| **Value proposition** | *Know where your loan is, get a reason for every decision, and never pay to be served*; for officials, one live record instead of paper reports |
| **Channels** | Web (officials and households with smartphones); USSD (any phone); SMS alerts; public parish pages |
| **Key activities** | Profiling and verification; application and appraisal; maker-checker decisions; repayment tracking; complaints and appeals; reporting |
| **Key partners** | MoFPED and the PDM Secretariat; local governments; PDM SACCOs; NIRA (identity, mocked here); telecoms and an SMS/USSD gateway such as Africa's Talking; banks and mobile money (payments outside the system) |
| **Key resources** | The shared database; trained parish staff; the parish help desk; the USSD short code |
| **Costs** | Hosting, SMS and USSD fees, training, support (see section 3.3) |
| **Public value (instead of revenue)** | Faster decisions; fewer trips; less corruption risk (reasons, maker-checker, bribery reports routed past the parish); better repayment through reminders and visibility; open figures for citizens |
| **Accountability** | Every change signed by a named official; the auditor reads everything; public parish figures |
